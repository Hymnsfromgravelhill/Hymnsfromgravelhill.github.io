# Changelog

## 0.05
- Settings: new "Book shelf layout" option to show the hymn books as tiles or as a list of long bars.

## 0.04
- Hymn lists now open sorted by hymn number in every book (Alphabetical and Book order are still available).

## 0.03
- New launcher icon: the book-and-note symbol on a navy background (it was showing as a solid white tile). Supports round, squircle and themed icons.

## 0.02
- Settings now credits From Gravel Hill Enterprises, with a link to fromgravelhill.ca.
- Fixed the build script so the app builds.
- Search: several typed words now find hymns containing that phrase first.
- Seed Sowers book renamed "Seed Sowers Hymnal (2015)".

## 0.01
- First numbered release of the Hymns from Gravel Hill app.
- Book shelf, search as you type, favorites, light/dark/auto theme, text size, keep-screen-on, share.
- All hymn books are built in and work offline.
